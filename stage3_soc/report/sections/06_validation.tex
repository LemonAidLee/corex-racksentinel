\section{Custom Firmware Validation and Testbench}\label{sec:validation}
% =====================================================================
\resultstrip{Show that the firmware meets \tabref{tab:decisions} and that the testbench detects faults.}
  {124 checks, 0 failures; 4 of 4 faults detected}
  {\tabref{tab:verif}, Figures~\ref{fig:matrix}–\ref{fig:applog}}

The application testbench \code{tb\_data\_center\_application.v} drives only the chip pins, as \code{./emu} does, and checks every reply byte and pin value; expected CRCs come from an independent bit-serial model. \figref{fig:matrix} shows its 12 cases. Because the platform stops a simulation after about 3\,ms, each case was run on its own on the ChipInventor platform (\code{FIRST\_RUN} = \code{LAST\_RUN} = $k$); the 12 platform logs add up to 124 checks with 0 failures, and a single Icarus Verilog run of all 12 cases gives the same totals. \tabref{tab:verif} summarizes the evidence.
